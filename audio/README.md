# 十三行行動博物館 - 音樂與音效資源說明

本專案已內建以 **Web Audio API** 即時演算合成的「十三行史前雅樂」（融合淡水河口海風、溫潤陶韻與沉浸氛圍弦樂），即使沒有放置任何外部音檔，也能在所有瀏覽器、甚至離線或直接點擊 HTML 本地開啟（`file:///`）時 100% 完美流暢播放！

---

## 🎵 如何替換為自訂背景音樂？

如果您有自己準備的背景輕音樂 MP3 / OGG 音檔：
1. 將您的音樂檔案重新命名為 **`bgm.mp3`**（或 `bgm.ogg`）。
2. 直接放入此 `audio/` 資料夾中（路徑為 `audio/bgm.mp3`）。
3. 重新整理網頁，系統將會**自動優先載入並播放**您的自訂音樂檔案！
4. 若無放置 `bgm.mp3` 或自訂檔案載入失敗，系統會**自動無縫切換**為內建的十三行沉浸雅樂，確保體驗絕不中斷。

---

## 🔔 按鈕音效

全站按鈕、翻牌卡、選單、題庫點選及測驗正解提示均具備細緻觸感音效，可於網頁右上角「🎵 音樂音效」或右下角浮動控制列隨時開啟或關閉。
